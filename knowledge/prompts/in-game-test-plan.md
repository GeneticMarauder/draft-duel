# Prompt: Write an in-game test plan

**Use when:** a change is built and the user will check it in TTS.
**Routes to:** `router.in-game-test-planner`.

```text
Write a short in-game test plan for <change>, for me to run in Tabletop Simulator.
Use router/in-game-test-planner/SKILL.md: setup (fresh save, seats, shortcuts like !draftauto),
numbered steps with what I should see, the reload check, and what to send back if it fails.
Keep it under 12 steps.
```
