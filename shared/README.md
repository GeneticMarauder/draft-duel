# Shared

Gameplay patterns built from several core areas, reusable by any mod.

| Skill | Pattern | Samples |
| --- | --- | --- |
| [card-privacy](card-privacy/SKILL.md) | Cards only their owner can see, kept private through handling and reloads | `private_cards.lua` |
| [table-layout](table-layout/SKILL.md) | Seat-relative layout and free-spot search | `seat_relative_layout.lua`, `free_spot.lua` |
| [rules-engine-pattern](rules-engine-pattern/SKILL.md) | Pure rules engine + thin TTS adapter | `pure_core_template.lua` |
| [counters-and-tokens](counters-and-tokens/SKILL.md) | Life counters and card-created tokens | `life_counters.lua`, `token_spawner.lua` |
| [custom-assets](custom-assets/SKILL.md) | Images TTS can load and never shows stale | — |
